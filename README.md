# AmiSynth

REAPER の JSFX として使える自作のシンセ・物理モデル音源・ドラムです。名前の由来は *LLM-friendly な synth*。

DSP はすべて「サンプル単位の素直なループ」で書かれていて、ブラウザ (AudioWorklet) 版と REAPER の JSFX (EEL2) 版が**サンプル単位で同じ音**を出します (ysfx で自動比較)。パラメーターは単位入りの名前と実値で扱うので、REAPER のオートメーションや MCP から名前だけで音色を読み書きできます。

| 音源 | 内容 |
| --- | --- |
| **Synth** | 2 オシレーター + ウェーブテーブルの減算式シンセ。モジュレーション・マトリクス、アルペジエーター、エフェクト付き |
| **Physical** | 弦・モーダル・擦弦・管・膜 / 板・ピアノ風の硬い弦・金管の物理モデルと、トーンホイール風オルガン |
| **Drums** | サンプルを使わない合成ドラム。GM 配置の 35〜81 がすべて鳴る |
| **Tuning** | 音は出さず、共通の音階を全トラックに配る JSFX |

内蔵プリセットはシンセ 78 種・物理モデル 103 種・ドラムキット 8 種です。

## REAPER で使う

`jsfx/` に Synth / Physical / Drums / Tuning の 4 つの JSFX があります。REAPER 6.74 以降が必要です。

[Releases](https://github.com/Lenqth/AmiSynth/releases) の `AmiSynth-jsfx-<版>.zip` は REAPER のリソースフォルダと同じ構成なので、Options → Show REAPER resource path で開いたフォルダにそのまま展開すれば使えます。リポジトリから入れる場合は次のとおりです。

```sh
# 配置先を確認してから (--dry-run を外して) コピーする
npm run install:reaper -- --resource "REAPERのリソースパス" --dry-run
```

手でコピーする手順や Actions への登録は [jsfx/README.md](jsfx/README.md#インストール) を参照してください。

- **プリセット**: 内蔵プリセットを REAPER のプリセットライブラリ (`jsfx/*.jsfx.rpl`) として同梱しています。FX ウィンドウのプリセット欄からそのまま選べます (チューニングは変わりません)。
- **AmiSynth Companion** (Lua)
  - 用途別のプリセット選択・保存
  - Synth の 4 マクロ (Brightness / Punch / Width / Pump)、機能別の詳細編集
  - 出力ピーク / RMS とボイス状況の表示、任意のレベル補正
  - ドラム 4 バスの配線アクション、MCP 向けの実値 / 正規化値カタログ
- **MCP から音色を作る**: `AmiSynth - Read sound.lua` で読み、差分を編集して `AmiSynth - Apply sound.lua` で適用します。差分は Web 版の JSON コピーと同じ形式で、1 回の Undo で適用され、範囲外の値は丸めて報告されます。そのほかの操作は `AmiSynth - Run.lua` にまとめて JSON で渡せます。
- **サイドチェイン**: Synth / Physical は入力ピン 3/4 を持ち、キックなどの音量で出力を下げられます (本物のポンピング)。Synth のモジュレーション・マトリクスのソースにも使えます。→ [詳細](jsfx/README.md#サイドチェイン-synth--physical)
- **ドラムのパーツ別出力**: 4 グループを別ピンに出し、グループごとにメインミックスから外せます (キック単体のサイドチェインなど)
  - キック
  - スネア・クラップ・リム
  - ハット・シンバル
  - タム・パーカッション
- **共通の音階**: 「AmiSynth Tuning」を 1 つ置けば全トラックが同じ音階に従います。音階はスライダー (MCP から書ける) か Scala ファイルで指定し、Slot を分ければ 1 曲で複数の音階を使えます。
- **テンポ同期**: アルペジエーター・LFO・ディレイは REAPER のテンポと拍位置に従います。

## 音源の機能

### Synth

- **オシレーター**: 2 基 + サブオシレーター
  - 波形: Saw / Pulse / Triangle / Sine (PolyBLEP)、Wavetable
  - パルス幅と PWM、ハードシンク、osc2→osc1 の FM
- **ウェーブテーブル**: 5 バンク × 8 フレーム。サンプルファイルを使わず計算で作ります
  - Basic Shapes: サイン→三角→ノコギリ→矩形
  - PWM Sweep: パルス幅 50 %→5 %
  - Vocal Formants: 母音 a・e・i・o・u
  - Harmonic Sweep: 倍音の帯が 5 オクターブ上昇
  - Digital: 8 ビットの XOR 波形
  - オクターブごとの帯域制限テーブル (ミップマップ) を音程で切り替え、段の境目はクロスフェードするので、高音でも折り返さず、ベンドやグライドでも波形が跳びません
  - 位置は LFO・フィルター EG・アンプ EG と、モジュレーション・マトリクスで動かせます
- **ノイズ**: ノイズ専用フィルター付き
  - ホワイト
  - ファミコン風の周期ノイズ 2 種
  - サンプル & ホールド
  - 合成 FX: 回転翼・群衆の拍手・破裂音・雨音
- **ユニゾン**: 最大 9 重・ステレオ。デチューンのカーブと外側の音量を調整できます
- **フィルター**: TPT SVF。ドライブ付き
  - タイプ: LP / HP / BP / ノッチ
  - 傾き: 12 / 24 dB
  - MIDI CC でカットオフを操作 (既定 CC74)
- **エンベロープ・LFO**
  - フィルター / アンプ ADSR
  - ノートごとのモジュレーション・エンベロープ (ADSR)
  - LFO × 2: 6 波形 + ダッキング形状、テンポ同期 (4 小節〜1/32・付点・3 連)
- **モジュレーション・マトリクス**: 4 スロット。量は行き先の単位 (cents・oct・dB など) で指定します
  - ソース: LFO 1 / LFO 2 / Mod Env / ベロシティ / キートラック / Mod Wheel / プレッシャー / ノートごとのランダム / Sidechain (JSFX のみ)
  - 行き先: ピッチ / カットオフ / レゾナンス / パルス幅 / Osc2 ピッチ / FM 量 / 音量 / パン / LFO 1・2 の速さ / ノイズ量 / Osc1・Osc2 の WT 位置
- **演奏**
  - 8 ボイス: Poly / Mono / Legato (数 ms の隙間もレガートとみなす Legato Window 付き)
  - グライド: 常時 / レガート時のみ
  - トランスポーズ、ピッチベンド、Mod ホイール、サステインペダル
  - アフタータッチ: チャンネル / ポリフォニック
- **アルペジエーター**: MIDI は「1 小節 1 和音」で済みます
  - モード: Up / Down / Up-Down / Random / As Played / Chord
  - 音価: 1/4〜1/32 (付点・3 連)
  - オクターブ幅、ゲート、スウィング、16 ステップのリズムゲート
  - 頭に戻る条件: 最初の押鍵 / 新しい和音 / 小節ごと / 流しっぱなし
- **エフェクト**: コーラス → ディレイ → リバーブ の順。どれも既定は Off で、On/Off と Mix 付き
  - コーラス: ステレオ、速さ・深さ
  - ディレイ: ms 指定またはテンポ同期、ピンポン、フィードバック、繰り返すほど暗くなるハイカット
  - リバーブ: オールパス 2 段 + 4 本の遅延線の FDN。長さ・広さ・高域の減衰

### Physical (物理モデル)

- **弦**: Karplus-Strong。ピック位置、ハンマー励起
  - シタール / 三味線のサワリ: 平たい駒への片側の接触で、高い倍音のビリつきが音の終わりまで続く
  - 三味線: 撥による弦の解放と短い皮・胴の響き
  - シタール: 24 本の共鳴弦によるステレオの余韻 (カスタム音律にも対応)
- **モーダル**: 2 極共振器 × 8 モード、13 素材
  - 鍵盤打楽器: マリンバ / ビブラフォン / グロッケン / カリンバ
  - 金属・ガラス: グラス / 鐘 / チューブラーベル / スティールドラム
  - ガムランなど: ガムラン・ゴング / ボナン / タムタム
  - 太鼓膜、弦のような倍音列 (Harmonic)
- **擦弦**: デジタル導波管 + 弓の摩擦曲線によるスティック・スリップ
  - 弓圧 / 弓速 / 弓の位置
  - 簡易な胴体共鳴
- **管楽器**: 息の圧力 / 揺らぎ / ノイズ / アンブシュア
  - クラリネット: リード + 円筒管
  - フルート: エアジェット + 管
  - サックス / オーボエ・ファゴット: リード + 円錐管
  - フリーリード: アコーディオン / ハーモニカ / リードオルガン (ミュゼットの 3 枚リードのうなり)
- **膜 / 板**: 2D 波動方程式の差分格子 (同時発音 3)
  - 円形膜 / 正方形板
  - 打点とマレットの硬さ
- **硬い弦 (ピアノ風)**
  - オールパスによる倍音のストレッチ
  - フェルトハンマーの非線形接触 (強く弾くほど明るい)
  - 16 共鳴の響板、1 音 2 本の弦のうなり
- **金管**: 唇リード + 管 + ベル。強く吹くほど明るい
  - トランペット / トロンボーン / ホルン / フリューゲルホルン
- **オルガン**: 物理モデルではなく加算合成のトーンホイール風
  - 9 本のドローバー (16' 〜 1')
  - パーカッション (2nd / 3rd)、キークリック

全モデル共通で次を使えます。

- **ロータリースピーカー**
  - ホーン: ドップラー + 音量の回転
  - ドラム: 音量の回転
  - Slow / Fast はゆっくり加減速し、Mod ホイールで Fast に切り替えられます
- **ギターアンプ**: 弦モデルと組み合わせてエレキギターに
  - タイプ: Clean / Crunch / Overdrive / Distortion
  - Amp Auto Level: ゲインを上げても音量を保つ
- **共通の調整**: ビブラート、部屋の響き (FDN リバーブ)、リリース、ベロシティ、ステレオ幅
- **サステインペダル (CC64)**
  - Auto (既定): 撥弦・ピアノと、太鼓膜以外のモーダル素材に効く
  - Off / All models (CC64) も選べる
  - ソステヌート (CC66) も同じモデルに効く
- **アフタータッチ**: 既定は無効
  - 息の圧力 (管・金管)、弓圧 (擦弦)
  - 明るさ (擦弦の駒・金管のベル)
  - ビブラートの深さ
- **内部状態の可視化** (Web 版、任意): 弦・管の中の波 / 弓のスティック・スリップ / 各モードの振幅 / 膜の変位 / 倍音のずれ

### Drums

すべて合成で、サンプルは使いません。GM 配置です。

- **キック・スネア系**: キック 36 / リム 37 / スネア 38 / クラップ 39
- **ハット・シンバル**: クローズ HH 42 / オープン HH 46 / クラッシュ 49 / ライド 51
- **タム**: ロータム 45 / ミッドタム 47 / ハイタム 50
- **パーカッション**
  - タンバリン 54 / カウベル 56 / ビブラスラップ 58
  - コンガ 63 / ティンバレス 65 / アゴゴ 67
  - シェイカー 70 / ホイッスル 72 / ギロ 74 / クラベス 75 / クイーカ 79 / トライアングル 81
- **そのほかの GM 打楽器**: 各パーツの音程・減衰違いとして鳴るので、35〜81 はすべて音が出ます
  - フロアタム 41・43、ハイミッドタム 48、チャイナ 52、ライドベル 53、スプラッシュ 55
  - ボンゴ 60・61、コンガ 62・64、ウッドブロック 76・77
  - ショートホイッスル 71、ショートギロ 73、ミュートクイーカ 78、ミュートトライアングル 80 など
- **調整**
  - クローズ HH によるチョーク
  - パーツごとの音程・減衰・トーン・音量・パン

### プリセットとチューニング

- **プリセット**
  - 音量は共通フレーズでおおむね -18 LUFS に揃えています (短い減衰の Pipa などは例外)。`node scripts/preset-loudness.js` で確認できます
  - 既定値との差分だけを書く JSON なので、LLM に作ってもらってそのまま貼れます
- **チューニング**: 12 平均律に依存しません。ピッチベンドやデチューンは cents で指定します
  - 任意の EDO
  - 周期の指定 (例: Bohlen-Pierce)
  - Scala (.scl) / cents / 比のリストによるカスタム音階

## Web 版 (おまけ)

ブラウザで音源を試すためのデモです。音は JSFX 版と同じです。

- **ピアノロール**: 4 小節のパターン + ドラムステップ。パターンは最大 32 個まで増やせ、曲順を並べた「ソング」として通して再生できます。元に戻す / やり直し (`Ctrl+Z` / `Ctrl+Shift+Z`) に対応しています。
- **MIDI**: .mid の読み込み (ch10 はドラムへ、Program Change から近いプリセットを選択) と書き出し。書き出した .mid はそのまま REAPER で鳴らせます (メロディ ch1、ドラム ch10)。
- **音声書き出し**: パターンや曲全体を WAV (16 bit) / MP3 (192 kbps) で書き出します。ピークと LUFS を表示します。
- **共有リンク**: 曲・音色・チューニングを URL の `#` 以降に圧縮して共有できます。
- **入力**
  - PC キーボード
  - 画面鍵盤: ピアノ・1 列・等音の格子 / 六角形 (スマホの縦持ちでも横向きに使える)
  - Web MIDI 入力 (ch10 → ドラム)
  - Press ストリップ: 押している間チャンネルプレッシャーを送る
- **その他**: ユーザープリセットの保存 (ブラウザ内)、JSON コピー / 貼り付け、チューニング欄から tuning.txt の書き出し。ブラウザのコンソールから `window.amisynth` (engine / app / setParam) で操作できます。

## 開発

```sh
npm install
npm run dev               # http://localhost:5173
npm test                  # DSP のユニットテスト (Node)
npm run build             # dist/ に静的ファイルを出力
npm run gen:jsfx          # params.js → JSFX のスライダー宣言・.rpl・generated/
npm run check:catalogs    # 生成物とカタログの整合チェック
npm run jsfx:tools        # ysfx をビルドして JSFX 比較テストを有効にする (任意)
npm run jsfx:compare      # JS 版と JSFX 版の出力をサンプル単位で比較
npm run audition:preset -- synth --preset "Formant Half-time Bass" --out .cache/audition
                          # 固定 MIDI・WAV・測定値を保存
npm run audition:timbre   # WAV・MIDI・プリセット JSON・試聴ページを生成
```

**リリース**: `package.json` と `clap/CMakeLists.txt` の version を上げてから `v<版>` のタグ (例: `v0.1.0`) を push すると、`.github/workflows/release.yml` が JSFX の zip と 3 OS の CLAP の zip を作り、GitHub Release に添付します (説明文は `.github/release-notes.md` + 自動生成の変更一覧)。タグと version が食い違うと失敗します。Actions から手動実行すると、公開せずに同じ zip を作るだけです。

### 設計上のポイント

- DSP コード (`src/dsp/*`) は Web Audio に依存せず、Node でもそのまま動きます。Web Audio の組み込み DSP ノードは使わず、AnalyserNode をスコープ表示にだけ使っています。
- Worklet へは **MIDI バイト列** (`[0x90, note, vel]` など) と **パラメーター値** だけを送ります。JSFX が REAPER から受け取るものと同じです。タイムスタンプ付き MIDI はサンプル単位で適用します (JSFX の `midirecv` オフセットに相当)。
- パラメーター ID は snake_case で単位入りです (`filter_cutoff_hz`, `amp_release_ms` など)。JSFX のスライダーは実値のまま (対数シェイプなし) なので、カットオフ 2000 Hz はそのまま `2000` と書けます。
