# AmiSynth

REAPER の JSFX として使える自作のシンセ・物理モデル音源・ドラムです。名前の由来は *LLM-friendly な synth*。

DSP はすべて「サンプル単位の素直なループ」で書かれていて、ブラウザ (AudioWorklet) 版と REAPER の JSFX (EEL2) 版が**サンプル単位で同じ音**を出します (ysfx で自動比較)。パラメーターは単位入りの名前と実値で扱うので、REAPER のオートメーションや MCP から名前だけで音色を読み書きできます。

| 音源 | 内容 |
| --- | --- |
| **Synth** | 2 オシレーター + ウェーブテーブルの減算式シンセ。モジュレーション・マトリクス、アルペジエーター、エフェクト付き |
| **Physical** | 弦・モーダル・擦弦・管・膜 / 板・ピアノ風の硬い弦・金管の物理モデルと、トーンホイール風オルガン |
| **Drums** | サンプルを使わない合成ドラム。GM 配置の 35〜81 がすべて鳴る |
| **Tuning** | 音は出さず、共通の音階を全トラックに配る JSFX |

内蔵プリセットはシンセ 78 種・物理モデル 103 種・ドラムキット 8 種です。

## REAPER で使う

`jsfx/` に Synth / Physical / Drums / Tuning の 4 つの JSFX があります。REAPER 6.74 以降が必要です。

```sh
# 配置先を確認してから (--dry-run を外して) コピーする
npm run install:reaper -- --resource "REAPERのリソースパス" --dry-run
```

手でコピーする手順や Actions への登録は [jsfx/README.md](jsfx/README.md#インストール) を参照してください。

- **プリセット**: 内蔵プリセットを REAPER のプリセットライブラリ (`jsfx/*.jsfx.rpl`) として同梱しています。FX ウィンドウのプリセット欄からそのまま選べます (チューニングは変わりません)。
- **AmiSynth Companion** (Lua): 用途別のプリセット選択・保存、Synth の 4 マクロ、機能別の詳細編集。出力ピーク / RMS とボイス状況の表示、任意のレベル補正、ドラム 4 バスの配線アクション、MCP 向けの実値 / 正規化値カタログも付属します。
- **MCP から音色を作る**: `AmiSynth - Read sound.lua` で読み、差分を編集して `AmiSynth - Apply sound.lua` で適用します。差分は Web 版の JSON コピーと同じ形式で、1 回の Undo で適用され、範囲外の値は丸めて報告されます。そのほかの操作は `AmiSynth - Run.lua` にまとめて JSON で渡せます。
- **サイドチェイン**: Synth / Physical は入力ピン 3/4 を持ち、キックなどの音量で出力を下げられます (本物のポンピング)。Synth のモジュレーション・マトリクスのソースにも使えます。→ [詳細](jsfx/README.md#サイドチェイン-synth--physical)
- **ドラムのパーツ別出力**: キック / スネア・クラップ・リム / ハット・シンバル / タム・パーカッションの 4 グループを別ピンに出し、グループごとにメインミックスから外せます。
- **共通の音階**: 「AmiSynth Tuning」を 1 つ置けば全トラックが同じ音階に従います。音階はスライダー (MCP から書ける) か Scala ファイルで指定し、Slot を分ければ 1 曲で複数の音階を使えます。
- **テンポ同期**: アルペジエーター・LFO・ディレイは REAPER のテンポと拍位置に従います。

## 音源の機能

### Synth

- **オシレーター**: 2 基 (Saw / Pulse / Triangle / Sine は PolyBLEP、Wavetable) + サブオシレーター。パルス幅と PWM、ハードシンク、osc2→osc1 の FM。
- **ウェーブテーブル**: 5 バンク × 8 フレーム (Basic Shapes / PWM Sweep / Vocal Formants / Harmonic Sweep / Digital)。サンプルファイルを使わず計算で作ります。オクターブごとの帯域制限テーブル (ミップマップ) を音程で切り替え、段の境目はクロスフェードするので、高音でも折り返さず、ベンドやグライドでも波形が跳びません。位置は LFO・フィルター EG・アンプ EG で動かせます。
- **ノイズ**: ホワイト、ファミコン風の周期ノイズ 2 種、サンプル & ホールド、回転翼・群衆の拍手・破裂音・雨音の合成 FX。ノイズ専用フィルター付き。
- **ユニゾン**: 最大 9 重・ステレオ。デチューンのカーブと外側の音量を調整できます。
- **フィルター**: LP / HP / BP / ノッチ、12 / 24 dB (TPT SVF)。ドライブ付き。MIDI CC でカットオフを操作できます (既定 CC74)。
- **エンベロープ・LFO**: フィルター / アンプ ADSR、ノートごとのモジュレーション・エンベロープ。LFO は 2 基 (6 波形 + ダッキング形状、テンポ同期 1/1〜1/32・付点・3 連)。
- **モジュレーション・マトリクス**: 4 スロット。ソース (LFO 1・2 / Mod Env / ベロシティ / キートラック / Mod Wheel / プレッシャー / ノートごとのランダム / JSFX では Sidechain) → 行き先 (ピッチ / カットオフ / レゾナンス / パルス幅 / Osc2 ピッチ / FM 量 / 音量 / パン / LFO の速さ / ノイズ量)。量は行き先の単位 (cents・oct・dB など) で指定します。
- **演奏**: 8 ボイス (Poly / Mono / Legato。数 ms の隙間もレガートとみなす Legato Window 付き)、グライド (常時 / レガート時のみ)、トランスポーズ、ピッチベンド、Mod ホイール、サステインペダル、アフタータッチ (チャンネル / ポリフォニック)。
- **アルペジエーター**: Up / Down / Up-Down / Random / As Played / Chord、1/4〜1/32 (付点・3 連)、オクターブ幅、ゲート、スウィング、16 ステップのリズムゲート、頭に戻る条件の選択。MIDI は「1 小節 1 和音」で済みます。
- **エフェクト**: コーラス → ディレイ (ms 指定またはテンポ同期、ピンポン、繰り返すほど暗くなるハイカット) → リバーブ (オールパス 2 段 + 4 本の遅延線の FDN)。どれも既定は Off です。

### Physical (物理モデル)

| モデル | 内容 |
| --- | --- |
| 弦 | Karplus-Strong。ピック位置、ハンマー励起。シタール / 三味線のサワリ (平たい駒への片側の接触による高い倍音のビリつき)、三味線の撥と皮・胴の響き、シタールの 24 本の共鳴弦 (カスタム音律にも対応) |
| モーダル | 2 極共振器 × 8 モード。マリンバ / ビブラフォン / グロッケン / グラス / 鐘 / 太鼓膜 / カリンバ / ガムラン・ゴング / ボナン / タムタム / スティールドラム / チューブラーベルなど 13 素材 |
| 擦弦 | デジタル導波管 + 弓の摩擦曲線によるスティック・スリップ。弓圧 / 弓速 / 弓の位置、簡易な胴体共鳴 |
| 管楽器 | クラリネット、フルート (エアジェット)、サックス / オーボエ・ファゴット (円錐管)、フリーリード (アコーディオン / ハーモニカ / リードオルガン、ミュゼットのうなり) |
| 膜 / 板 | 2D 波動方程式の差分格子。円形膜 / 正方形板、打点とマレットの硬さ (同時発音 3) |
| 硬い弦 | ピアノ風。オールパスによる倍音のストレッチ、フェルトハンマーの非線形接触、16 共鳴の響板、1 音 2 本の弦のうなり |
| 金管 | 唇リード + 管 + ベル。トランペット / トロンボーン / ホルン / フリューゲルホルン |
| オルガン | 加算合成のトーンホイール風。9 本のドローバー、パーカッション、キークリック |

全モデル共通で次を使えます。

- **ロータリースピーカー**: ホーン (ドップラー + 音量) とドラム (音量)。Slow / Fast はゆっくり加減速し、Mod ホイールで Fast に切り替えられます。
- **ギターアンプ**: Clean / Crunch / Overdrive / Distortion。弦モデルと組み合わせてエレキギターに。Amp Auto Level でゲインを上げても音量を保てます。
- **共通の調整**: ビブラート、部屋の響き (FDN リバーブ)、リリース、ベロシティ、ステレオ幅。
- **サステインペダル (CC64)**: 既定の Auto は撥弦・ピアノ・膜以外のモーダル素材に効きます。Off / 全モデルも選べます。
- **アフタータッチ**: 息の圧力、弓圧、明るさ、ビブラートの深さに割り当てられます (既定は無効)。

### Drums

すべて合成で、サンプルは使いません。GM 配置で、主なパーツは次のとおりです。

キック 36 / リム 37 / スネア 38 / クラップ 39 / クローズ HH 42 / ロータム 45 / オープン HH 46 / ミッドタム 47 / クラッシュ 49 / ハイタム 50 / ライド 51 / タンバリン 54 / カウベル 56 / ビブラスラップ 58 / コンガ 63 / ティンバレス 65 / アゴゴ 67 / シェイカー 70 / ホイッスル 72 / ギロ 74 / クラベス 75 / クイーカ 79 / トライアングル 81

残りの GM 打楽器 (フロアタム、チャイナ、ボンゴ、ウッドブロックなど) は各パーツの音程・減衰違いとして鳴るので、35〜81 はすべて音が出ます。クローズ HH によるチョーク、パーツごとの音程・減衰・トーン・音量・パンを調整できます。

### プリセットとチューニング

- **プリセット**: 音量は共通フレーズでおおむね -18 LUFS に揃えています (短い減衰の Pipa などは例外)。`node scripts/preset-loudness.js` で確認できます。プリセットは既定値との差分だけを書く JSON なので、LLM に作ってもらってそのまま貼れます。
- **チューニング**: 12 平均律に依存しません。任意の EDO・周期 (例: Bohlen-Pierce)・Scala (.scl) / cents / 比のリストによるカスタム音階に対応し、ピッチベンドやデチューンは cents で指定します。

## Web 版 (おまけ)

ブラウザで音源を試すためのデモです。音は JSFX 版と同じです。

- **ピアノロール**: 4 小節のパターン + ドラムステップ。パターンは最大 32 個まで増やせ、曲順を並べた「ソング」として通して再生できます。元に戻す / やり直し (`Ctrl+Z` / `Ctrl+Shift+Z`) に対応しています。
- **MIDI**: .mid の読み込み (ch10 はドラムへ、Program Change から近いプリセットを選択) と書き出し。書き出した .mid はそのまま REAPER で鳴らせます (メロディ ch1、ドラム ch10)。
- **音声書き出し**: パターンや曲全体を WAV (16 bit) / MP3 (192 kbps) で書き出します。ピークと LUFS を表示します。
- **共有リンク**: 曲・音色・チューニングを URL の `#` 以降に圧縮して共有できます。
- **入力**: PC キーボード、画面鍵盤 (ピアノ・1 列・等音の格子 / 六角形、スマホの縦持ちでも横向きに使える)、Web MIDI 入力、プレッシャーを送る Press ストリップ。
- **その他**: ユーザープリセットの保存 (ブラウザ内)、JSON コピー / 貼り付け、チューニング欄から tuning.txt の書き出し。ブラウザのコンソールから `window.amisynth` (engine / app / setParam) で操作できます。

## 開発

```sh
npm install
npm run dev               # http://localhost:5173
npm test                  # DSP のユニットテスト (Node)
npm run build             # dist/ に静的ファイルを出力
npm run gen:jsfx          # params.js → JSFX のスライダー宣言・.rpl・generated/
npm run check:catalogs    # 生成物とカタログの整合チェック
npm run jsfx:tools        # ysfx をビルドして JSFX 比較テストを有効にする (任意)
npm run jsfx:compare      # JS 版と JSFX 版の出力をサンプル単位で比較
npm run audition:preset -- synth --preset "Formant Half-time Bass" --out .cache/audition
                          # 固定 MIDI・WAV・測定値を保存
npm run audition:timbre   # WAV・MIDI・プリセット JSON・試聴ページを生成
```

### 構成

```
src/dsp/params.js      パラメーター定義 (名前・範囲・既定値・単位・説明)。唯一の定義元
src/dsp/lib.js         共通 DSP: オシレーター, SVF, 1 pole, ADSR, 減衰 EG, ノイズ, チューニング, エフェクト部品
src/dsp/synth.js       シンセ本体 (init / update / note_on / render)
src/dsp/wavetable.js   ウェーブテーブル (計算で作るテーブル、帯域制限のミップマップ、オシレーター)
src/dsp/drums.js       ドラム本体
src/dsp/phys.js        物理モデル音源
src/presets/*.js       内蔵プリセット (既定値からの差分だけを記述)
src/worklets/*.js      AudioWorklet ラッパー (MIDI バイト列 + パラメーターだけを受け取る)
src/lib/               メインスレッド: エンジン、状態、シーケンサー、チューニング補助
src/lib/song.js        パターン / 曲順のデータと検査 (history.js = 元に戻す、share.js = 共有リンク)
src/ui/                Svelte コンポーネント
scripts/               JSFX 生成、REAPER への配置、試聴・測定・整合チェック
jsfx/                  JSFX 本体、ReaScript (reaper/)、生成物 (generated/)
docs/                  MIDI 対応表、制作ワークフロー、音色調整、アジア楽器プリセット
```

### 設計上のポイント

- DSP コード (`src/dsp/*`) は Web Audio に依存せず、Node でもそのまま動きます。Web Audio の組み込み DSP ノードは使わず、AnalyserNode をスコープ表示にだけ使っています。
- Worklet へは **MIDI バイト列** (`[0x90, note, vel]` など) と **パラメーター値** だけを送ります。JSFX が REAPER から受け取るものと同じです。タイムスタンプ付き MIDI はサンプル単位で適用します (JSFX の `midirecv` オフセットに相当)。
- パラメーター ID は snake_case で単位入りです (`filter_cutoff_hz`, `amp_release_ms` など)。JSFX のスライダーは実値のまま (対数シェイプなし) なので、カットオフ 2000 Hz はそのまま `2000` と書けます。
