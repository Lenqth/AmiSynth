# AmiSynth

ブラウザで動く自作シンセ & ドラムマシンのデモ。DSP はすべて AudioWorklet 内の
「サンプル単位の素直なループ」で書かれていて、REAPER の JSFX (EEL2) へほぼ機械的に
移植できる形にしてあります。名前の由来は *LLM-friendly な synth*。

- **シンセ**: 2 オシレーター (Saw / Pulse / Triangle / Sine, PolyBLEP、Wavetable) + サブオシレーター +
  ノイズ (ホワイト / ファミコン風の周期ノイズ 2 種 / サンプル&ホールド、ノイズ専用フィルター)、
  パルス幅と PWM、ハードシンク、osc2→osc1 の FM、ユニゾン (最大 9 重・ステレオ、デチューンのカーブと外側の音量)、
  グライド (常時 / レガート時のみ)、ドライブ、フィルター (LP / HP / BP / ノッチ, 12/24 dB, TPT SVF)、フィルター/アンプ ADSR、
  LFO (6 波形 + ダッキング形状、テンポ同期 (1/1〜1/32・付点・3 連)、ピッチ / フィルター / PWM / トレモロ)、
  8 ボイス (Poly / Mono / Legato)、トランスポーズ、ピッチベンド / モジュレーションホイール、サステインペダル、
  MIDI CC でカットオフ (既定 CC74)
  - **ウェーブテーブル**: 各オシレーターの波形で Wavetable を選ぶと、バンク内の位置 (0〜1) で音色が変わる。
    バンクは 5 種 (Basic Shapes: サイン→三角→ノコギリ→矩形 / PWM Sweep: パルス幅 50 %→5 % /
    Vocal Formants: 母音 a・e・i・o・u / Harmonic Sweep: 倍音の帯が 5 オクターブ上昇 / Digital: 8 ビットの XOR 波形)、
    各 8 フレーム。サンプルファイルは使わず起動後に計算で作る (初めてバンクを選んだときに 1 回だけ)。
    オクターブごとの帯域制限テーブル (ミップマップ、逆 FFT で倍音を加算) を音程に応じて切り替えるので高音でも折り返さない。
    各段の上側半オクターブでは次の段 (倍音が半分なので折り返さない) へ直線でクロスフェードし、境目ちょうどで次の段だけになるので、ベンドやグライドで段をまたいでも波形が跳ばない。
    テーブル内とフレーム間は直線補間。位置は LFO・フィルター EG・アンプ EG で動かせる (量は ±1、両オシレーター共通)
  - **エフェクト** (ボイスを足し合わせた後に コーラス → ディレイ → リバーブ の順。どれも既定 Off なので既存の音色は変わらない):
    ステレオコーラス (速さ・深さ)、ステレオディレイ (ms 指定、またはテンポ同期 1/1〜1/32・付点・3 連、ピンポン、フィードバック、
    繰り返すほど暗くなるハイカット)、コンパクトなアルゴリズミック・リバーブ (拡散用オールパス 2 段 + Physical の部屋の響きと共通の
    4 本の遅延線による FDN。長さ・広さ・高域の減衰)。それぞれ On/Off と Mix (ドライ / ウェットの割合) 付き。
    ディレイの同期は Web 版は BPM、JSFX は REAPER のテンポに従う
  - **モジュレーション**: 2 つ目の LFO (LFO 1 と同じ波形・テンポ同期)、ノートごとのモジュレーション・エンベロープ (ADSR)、
    4 スロットのモジュレーション・マトリクス。ソース (LFO 1 / LFO 2 / Mod Env / ベロシティ / キートラック / Mod Wheel /
    プレッシャー / ノートごとのランダム) → 行き先 (ピッチ / カットオフ / レゾナンス / パルス幅 / Osc2 ピッチ / FM 量 / 音量 /
    パン / LFO 1・2 の速さ / ノイズ量) × 量。量は行き先の単位 (cents・oct・dB など) で指定。既定は全スロット Off
  - **アフタータッチ**: チャンネルプレッシャー / ポリフォニック・アフタータッチをマトリクスのソース「Pressure」として使える
  - **アルペジエーター**: Up / Down / Up-Down / Random / As Played / Chord (和音の刻み)、1/4〜1/32 (付点・3 連)、
    オクターブ幅、ゲート、スウィング、16 ステップのリズムゲート。ホストのテンポと拍位置に同期
    (JSFX は REAPER のテンポ、Web 版は BPM とピアノロール)。MIDI は「1 小節 1 和音」で済む
- **物理モデル (Physical)**: 7 モデル
  - 弦 (Karplus-Strong: 遅延線 + ループ内ローパス、ピック位置、ハンマー励起)
  - モーダル合成 (2 極共振器 × 8 モード、マリンバ / ビブラフォン / グロッケン / グラス / 鐘 / 太鼓膜 / カリンバ等の素材表。ガムラン・ゴング / ボナン / タムタムを含む 11 種)
  - 擦弦 (デジタル導波管 + 弓の摩擦曲線によるスティック・スリップ、弓圧 / 弓速 / 弓の位置、簡易な胴体共鳴)
  - 管楽器 (クラリネット = リード + 円筒管 + 高域が逃げる反射、フルート = エアジェット (Fletcher / Verge 型) + 管、サックス / オーボエ・ファゴット = リード + 円錐管 (全倍音。ダブルリードは鼻にかかった高域)。息の圧力 / 揺らぎ / ノイズ / アンブシュア)
  - 膜 / 板 (2D 波動方程式の差分格子、円形膜 / 正方形板、打点 / マレットの硬さ。同時発音 3)
  - 硬い弦 (ピアノ風: ループ内のオールパスで分散 → 実測に近い倍音のストレッチ、フェルトハンマーの非線形接触モデル (強く弾くほど明るい)、16 共鳴の響板、1 音 2 本の弦のうなり)
  - 金管 (唇リード: 音程に合わせた唇の共振器 + 2 周期ぶんの管 + 高音が逃げるベル。強く吹くほど明るい。トランペット / トロンボーン / ホルン / フリューゲルホルン)
  - ギターアンプ (Clean / Crunch / Overdrive / Distortion: プリ EQ、非対称クリップ、キャビネット風フィルター)。弦モデルと組み合わせてエレキギター
  - 共通: ビブラート (遅延線モデル)、部屋の響き (4 本の遅延線による FDN リバーブ)、リリース、ベロシティ、ステレオ幅
  - CC64サステインペダル: 既定Autoで撥弦・ピアノ・膜以外のモーダル素材に対応。Off／全モデルOnも選択でき、Web版にはSustainボタン付き
  - アフタータッチ (チャンネルプレッシャー / ポリフォニック): 息の圧力 (管・金管)・弓圧 (擦弦)、明るさ (擦弦の駒・金管のベル)、
    ビブラートの深さへ割り当て可能 (Pressure グループ。既定はすべて 0 = 無効)
  - 任意で内部状態の可視化 (弦・管の中の波 / 弓のスティック・スリップ / 各モードの振幅 / 膜の変位 / 倍音のずれ) — OFF の間は追加負荷なし
- **ドラム** (サンプル不使用・全部合成, GM 配置): キック 36 / リム 37 / スネア 38 / クラップ 39 /
  クローズ HH 42 / ロータム 45 / オープン HH 46 / ミッドタム 47 / クラッシュ 49 / ハイタム 50 /
  ライド 51 / カウベル 56 / シェイカー 70。クローズ HH によるチョーク、パーツごとに音程・減衰・トーン・音量・パン (+α)。
  JSFX 版はパーツ別出力 (キック / スネア・クラップ・リム / ハット・シンバル / タム・パーカッション) 付きで、
  グループごとにメインミックスから外せる (キック単体のサイドチェインなど)
- **プリセット**: シンセ 47 種 (ウェーブテーブル 5 種、エフェクトを使うパッド / リード / プラック / ダブ風コード 5 種を含む)・物理モデル 42 種 (エレキギター 6 種を含む。モジュレーション・マトリクス / アフタータッチの見本はシンセ 4 種・物理モデル 3 種)・ドラムキット 8 種を内蔵。どれも同じフレーズで -18 LUFS に揃えてある
  (ジャンルを変えても音量の基準がずれない。`node scripts/preset-loudness.js` で確認)。ユーザープリセット保存 (ブラウザ内)、
  JSON コピー / 貼り付け (既定値との差分だけを書く形式なので、LLM に作ってもらってそのまま貼れる)
- **チューニング**: 12 平均律に依存しない。任意の EDO・周期 (例: Bohlen-Pierce)・
  Scala (.scl) / cents / 比のリストによるカスタム音階。ピッチベンドやデチューンは cents 指定。
  JSFX 版は「AmiSynth Tuning」(音階を持つ JSFX) を 1 つ置けば全トラックが同じ音階に従う。音階はスライダー
  (MCP から書ける) か Scala ファイルで指定し、Slot を分ければ 1 曲で複数の音階を使える
  (Web 版のチューニング欄から値のコピー / tuning.txt の書き出しができる)
- **4 小節ピアノロール** + ドラムステップ (サンプル精度でスケジューリング)
  - **複数パターン + ソングモード**: 4 小節のパターンを A, B, C… と増やせる (新規 / 複製 / 削除 / 名前変更、最大 32 個)。
    曲順 (アレンジ) にパターンと繰り返し回数を並べ、「パターンループ」(編集中のパターンだけ、従来どおり) と
    「ソング」(曲順どおりに通して再生し、最後まで行ったら先頭へ) を切り替えられる。パターンの切れ目もサンプル単位で正確につながる。
    以前のバージョンで保存したパターンは、そのままパターン A として読み込まれる
  - **元に戻す / やり直し**: ノートやドラムの入力、パターン・曲順の編集を `Ctrl+Z` / `Ctrl+Shift+Z` (`Ctrl+Y`) か
    画面の「↶ 戻す」「↷ やり直し」ボタンで。ドラッグやドラムのなぞり入力は 1 回の操作でまとめて 1 ステップ
  - **MIDI 読み込み**: .mid (format 0 / 1) を「このパターン」(最初の 4 小節) か「ソング」(4 小節ずつのパターンに分割し、
    同じ内容のパターンは共有・連続は繰り返し回数にまとめる) として読み込む。ch10 は GM 配置でドラムパートへ
    (近い音色は寄せる: 35→キック, 40→スネア, 44→クローズ HH など。対応パートのない音は省く)、それ以外はピアノロールへ。
    16 分音符のグリッドに揃え、ベロシティはそのまま。テンポは最初のテンポを使う (拍子は 4/4 とみなす)
  - **共有リンク**: 「🔗 共有リンクをコピー」で、曲 (全パターンと曲順)・音色 (プリセットと同じく既定値との差分)・チューニングを
    URL の `#` 以降に圧縮して詰める (`#s1.…` = deflate + base64url、`s1` は形式のバージョン)。開くとそのまま読み込まれる
    (このブラウザに保存済みの作業があるときは確認してから)。URL から読んだ値はすべて検査し、範囲外は丸め、不正な値は捨てる
- PC キーボード / 画面鍵盤 (ピアノ・1 列・等音の格子 / 六角形、全画面モード。縦持ちのスマホ / タブレットでは画面内で 90° 回転して横向きに使える) / Web MIDI 入力 (ch10 → ドラム)。
  ベンド・Mod ホイールの横に **Press** ストリップ (押している間チャンネルプレッシャーを送り、離すと 0 に戻る。
  タッチの押す強さはブラウザでは当てにならないため)。外部 MIDI のアフタータッチもそのまま音源へ渡す。
  等音配列では PC キーボードの段 (Z 段〜数字段) がそのまま格子 / 六角形の段になる
- **JSFX 版 (REAPER)**: `jsfx/` に Synth / Physical / Drums と、共通の音階を持つ Tuning。Web 版とサンプル単位で同じ音 (ysfx で自動比較)。
  スクリプトの配置・Actionsへの登録・MCPからの呼び出し → [ReaScript / MCPガイド](jsfx/reaper/README.md)。`npm run install:reaper -- --resource "REAPERのリソースパス" --dry-run` で配置先を確認できます。MCP からは `AmiSynth - Read sound.lua` / `AmiSynth - Apply sound.lua` で、Web 版の JSON コピーと同じ差分形式のまま音色を読み書きできます(1 回の Undo、範囲外は丸めて報告)。
  CC・ベンド・ペダル・チャンネル・未対応メッセージの一覧 → [MIDI対応表](docs/MIDI.md)
  AmiSynth Companion で用途別プリセット選択・保存、4マクロ、機能別の詳細編集。出力ピーク／RMSとボイス状況の表示、任意のレベル補正、ドラム4バス配線アクション、MCP向け実値／正規化値カタログも付属。
  ピアノロールの「MIDI 書き出し」で作った .mid (ソングモードでは曲全体) をそのまま REAPER で鳴らせる → [jsfx/README.md](jsfx/README.md)
- **音声書き出し**: ピアノロールのパターン (ソングモードでは曲全体) を WAV (16 bit) / MP3 (192 kbps) で書き出し (ループ回数・ノーマライズ指定可、余韻まで。ピークと LUFS を表示)。再生と同じ DSP を Web Worker でオフライン実行するので、オーディオを開始していなくても書き出せる

## 開発

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # DSP のユニットテスト (Node)
npm run build      # dist/ に静的ファイルを出力
npm run gen:jsfx   # params.js → JSFX のスライダー宣言 (jsfx/*.jsfx と jsfx/generated/)
npm run jsfx:tools # ysfx をビルドして JSFX 比較テストを有効にする (任意)
```

## 構成

```
src/dsp/params.js      パラメータ定義 (名前・範囲・既定値・単位・説明) — 唯一の定義元
src/dsp/lib.js         共通 DSP: オシレーター, SVF, 1 pole, ADSR, 減衰 EG, ノイズ, チューニング, エフェクト部品 (コーラス / エコー / FDN リバーブ)
src/dsp/synth.js       シンセ本体 (init / update / note_on / render)
src/dsp/wavetable.js   ウェーブテーブル (計算で作るテーブル、帯域制限のミップマップ、オシレーター)
src/dsp/drums.js       ドラム本体
src/dsp/phys.js        物理モデル音源 (弦 / モーダル / 擦弦 / 管 / 膜・板 / 硬い弦)
src/presets/*.js       内蔵プリセット (既定値からの差分だけを記述)
src/worklets/*.js      AudioWorklet ラッパー (MIDI バイト列 + パラメータだけを受け取る)
src/lib/               メインスレッド: エンジン、状態、シーケンサー、チューニング補助
src/lib/song.js        パターン / 曲順のデータと検査 (history.js = 元に戻す、share.js = 共有リンク)
src/ui/                Svelte コンポーネント
scripts/gen-jsfx-sliders.js  params.js → JSFX slider 宣言 / params.json / presets.json
jsfx/                  JSFX 移植メモと生成物
```

設計上のポイント:

- DSP コードは Web Audio に依存しない (`src/dsp/*` は Node でもそのまま動く。テスト参照)。
  Web Audio の組み込み DSP ノード (Oscillator / BiquadFilter / Gain 等) は使っていない。
  AnalyserNode をスコープ表示のためだけに接続している。
- Worklet へは **MIDI バイト列** (`[0x90, note, vel]` など) と **パラメータ値** だけを送る。
  JSFX が REAPER から受け取るものと同じ。タイムスタンプ付き MIDI はサンプル単位で適用
  (JSFX の `midirecv` オフセットに相当)。
- パラメータ ID は snake_case で単位入り (`filter_cutoff_hz`, `amp_release_ms`, …)。
  REAPER のオートメーションや MCP から名前だけで意味が分かるようにしている。
  JSFX のスライダーは実値のまま (対数シェイプなし) なので、カットオフ 2000 Hz はそのまま `2000` と書ける。
- ブラウザのコンソールから `window.amisynth` (engine / app / setParam) で操作可能。

## デプロイ (Cloudflare Workers, 静的アセット)

`wrangler.jsonc` は Worker スクリプトなしで `dist/` を配信する設定です。

### 第一候補: Workers Builds (GitHub 連携で自動デプロイ)

1. Cloudflare ダッシュボード → **Workers & Pages** → **Create** → **Import a repository**
2. この GitHub リポジトリを選択
3. ビルド設定
   - Build command: `npm run build`
   - Deploy command: `npx wrangler deploy`
   - (Non-production branch deploy command: `npx wrangler versions upload`)
4. 以後、push するたびに自動でビルド & デプロイされます

> 本番以外のブランチでは Workers Builds が `npx wrangler preview` を **ビルドコマンドなしで**
> 実行するため、`package.json` の `prepare` スクリプトで `npm clean-install` 時に
> `vite build` が走るようにしてあります (`wrangler preview` は起動直後に `dist/` の存在を確認するため)。

### 代替: API トークンで wrangler deploy

```sh
export CLOUDFLARE_API_TOKEN=...   # "Edit Cloudflare Workers" テンプレートのトークン
export CLOUDFLARE_ACCOUNT_ID=...
npm run deploy                     # = vite build && wrangler deploy
```

(`wrangler login` は不要。サンドボックス環境ではネットワーク許可に `api.cloudflare.com` が必要)
