# 音色の調整と比較

シタール・三味線の信号解析と、FXの似方／フリーリード低音域のノイズについてのフィードバックをもとに調整しています。聴感上の自然さを数値だけで確定した変更ではありません。

## シタール・三味線

最初の比較セットのcandidateを内蔵プリセットへ反映しました。以下の表は初回のダンピング調整で、その後に追加した励振・共鳴処理は次項のとおりです。

| 音色 | String Dampingの変更 | 変更していない部分 |
|---|---|---|
| Sitar | 0.12 → 0.08 | Sawari 0.65、励振、ピック位置、Decay、Release |
| Shamisen | 0.25 → 0.18 | Sawari 0.35、励振、ピック位置、Decay、Release |

ダンピングを弱めて高音域の成分を残しやすくします。最初の測定では、Sitarの1秒間の減衰差は0.4 dB未満で、MIDI 64の倍音8–24比の増加は約1.8 dBでした。ShamisenのMIDI 76では同じ測定窓のRMS低下が約63 dBから約54 dBへ変わりました。全音域で余韻が一様に伸びる変更ではありません。

添付レビューの4 kHz以上の比率には、倍音と広帯域成分の両方が含まれます。また、最大サンプル間差だけではDSPクリックを特定できません。今回、サワリの独立した減衰モデルや再発音時の位相処理は、その推測だけを根拠に変更していません。発音直後と減衰途中の音色は試聴で確認してください。

### 撥のアタックと共鳴弦

PhysicalのStringへ次のコントロールを追加しました。既存の80スライダーの後ろ（81–86）へ追加し、従来のパラメータ番号は維持しています。Plectrum / Body Mix / Sympathetic Mixの初期値は0で、他の既存プリセットの音には適用しません。WebとJSFXで同じ処理を使います。

| コントロール | 作用 |
|---|---|
| String Plectrum | ノイズによる弦の初期振動に、撥で変位させて離した弦の形を混ぜる。発音時には皮への短い接触パルスも生成する |
| Plectrum Hardness | 接触時間を短くする。ベロシティが低いと柔らかくなる。次の発音から反映 |
| String Body Mix | 駒を通じた弦の振動と接触パルスで、950 / 2300 / 4800 Hzの短い胴・皮の共鳴を励起する |
| Sympathetic Mix | 全演奏弦の出力で共有の24共鳴器を励起し、左右へ控えめに振り分ける。発音ごとの重複した共鳴バンクは作らない |
| Sympathetic Decay | 共鳴のT60。高い共鳴器ほど少し短く、長い設定ほど立ち上がりもゆっくりになる |
| Sympathetic Root | 最低のMIDIキー。そこから24連続の音階段階を楽器の音律で調律する。標準音律では2オクターブの半音階で、曲の音階だけを選別する機能ではない |

ShamisenはPlectrum 0.45 / Hardness 0.95 / Body Mix 0.45を有効にしました。胴・皮の周波数と減衰は実測値にフィットしたものではなく、聴感調整用の近似です。弦の振動と撥の直接接触の両方で皮が鳴る構成は、[三味線の発音機構の解析](https://www.jstage.jst.go.jp/article/jasj/51/9/51_KJ00001450787/_article/-char/ja)を参考にしています。

SitarはSympathetic Mix 0.7 / Decay 4200 ms / Root 60を有効にし、Room Mixを0.15から0.08へ下げました。Rootは曲の音域に合わせて変更できます。カスタム／共有音律に追従し、演奏弦のピッチベンドには追従しません。共鳴弦の音律・Root・Decayが変わると古い余韻を消して再調律します。Mixの量だけの変更は余韻を維持し、0または別モデルへの切り替えはバンクを消去します。ノートオフとCC64の解除では共鳴自体の余韻が残ります。

固定した共鳴器を入力で励起する合成手法には[Sympathetic Sitarの実装例](https://github.com/stefdoerr/sitar)があります。今回の処理はそのコードを取り込んだものではなく、既存のAmiSynth共鳴器で実装した近似です。実物の共鳴弦同士の相互作用や曲ごとの調弦はまだモデル化していません。

試聴はCloudflareのブランチプレビューでSitar / Shamisenを選び、単音の強弱、連打、ノートオフ後の響きを確認します。今回から比較ページは作成しません。共通の5秒テストフレーズではSitar −18.04 LUFS / Shamisen −17.94 LUFSへ音量を再補正しましたが、自然さは聴感確認が必要です。

初回実装への「三味線がポクッと聞こえる」「シタールの効果が分かりにくい」という試聴結果を受け、次の調整を行いました。

- 三味線: 430 Hz / 80 msの強い低域共鳴を除去し、短い高域の皮共鳴へ変更。接触パルスは正の一方向から接触・解放の双極性へ変更し、Plectrumの変位成分とBody Mixも減らしました。固定パラメータ・Roomなし・MIDI 60の最初の50 msで、Body Mixの有無による差分の0–1.5 kHz / 1.5–8 kHzエネルギー比は旧処理 +16.08 dB → 新処理 −15.71 dBです。皮の追加成分が低域に偏らないことを確認する指標で、自然さの評価値ではありません。
- シタール: 共鳴出力の係数を0.3から2.4へ増やし、左右配分を30:70から15:85へ拡大。共鳴器の調律・減衰とMix値0.7は維持しています。固定音量−12 dB・Room/通常のStereo Widthなし・velocity 100・MIDI 48/60/64/69/76・0.1–1秒のステレオ出力で、Sympathetic Mix 0.7と0の差分RMS / Mix 0のRMSは旧処理2.3–4.6% → 新処理20.7–41.5%になりました。差分には位相と左右配分の変化も含まれます。

音量自体で効果を大きく感じさせないよう、プリセットのVolumeも共通フレーズに合わせて再補正しています。更新後のプレビューでプリセットを選び直して確認してください。

## フリーリードの低音域

対象はPhysicalのWind Type = Free reed（Accordion / Bandoneon / Harmonica / Reed Organ）。

以前は息圧へ白色ノイズを加え、リードの流量をサンプル間差分で放射音へ変換していました。放射ゲインは基本周波数に合わせて `1 / (2 * sin(pi * hz / sr))` で正規化するため、息圧の高速ノイズまで低音ほど大きく増幅されていました。

息圧へ加えるBreath Noiseの変動を、既存の5 Hz低域通過済みの息圧揺らぎへ変更しました。別経路の高域の息ノイズは残し、リードの音程、ムゼット、放射ゲインは維持しています。クラリネット・フルート・サックス・ダブルリードの処理は対象外です。

確認例（48 kHz、Accordion、MIDI 28、velocity 100、Room/Vibratoなし、0.5–2秒）:

| 測定 | 修正前 | 修正後 |
|---|---:|---:|
| Breath Noise 0.1と0の出力差分RMS / Noise 0のRMS | +14.55 dB | −37.69 dB |

同じパラメータと乱数初期値で測定した、Breath Noiseによる**出力変化の比**です。差分には息圧による音色変化も含まれ、単独のノイズ成分の厳密なSNRではありません。プリセット音量を再調整する前の比較ですが、比率の改善は音量の変更だけでは生じません。

## 合成によるFX

発音中にNoise TypeをFXへ／FX間で変更した場合も、各ボイスの拍手・雨粒タイマーをずらして初期化します。同じタイプのまま音量などを変更しても状態はリセットしません。Shotはタイプ切り替えでは発火せず、新しいノートオンでだけ発火します。

Synthの既存Noise Typeへ4方式を追加しました。White / Chip Long / Chip Short / Sample & Holdは従来の値0–3のままです。スライダーの追加・並べ替えはありません。

| Noise Type | 値 | 作る音 | Noise Clockの作用 |
|---|---:|---|---|
| Rotor | 4 | 周期的な低い圧力パルスと減衰する空気音 | 回転翼の周期を変更（0で11回/秒） |
| Crowd Claps | 5 | 18組の独立したタイマーで、低域を抑えた短い拍手を重ねる | 拍手の密度を変更 |
| Shot | 6 | 短い広帯域の破裂と、ごく短い初期反射 | 発音の進行速度を変更 |
| Rain | 7 | 連続した雨のざわめきと、強さ・共鳴周波数の異なる短い雨滴音 | 雨滴の密度を変更 |

Noise Levelで音量を調整し、通常のFilter / Amp Envelope / Effectsへ送ります。これらのFXソース自体はMIDI音高に依存しません。Filter Key Trackingなどの後段の設定では、音色を音高に応じて変えられます。

Noise Levelを0にしている間もFXの時計は進みます。後から音量を上げても、古いnote-onの破裂音を再生しません。

Helicopter / Applause / Gunshotプリセットにそれぞれ採用しています。Helicopterは四角波で一様なノイズを切る方式から、1回ごとに形のあるパルスへ変更しました。Applauseは間隔と強さの異なる短い発音を18組で重ねています。低域を抑え、6 msの減衰時定数で一発の胴鳴りを短くして、少人数の打撃が独立して聞こえる傾向を減らす狙いです。Gunshotは50〜150 Hz付近の音程付きの成分を除き、1.5 msの減衰時定数の鋭い破裂音と7 ms後の短い初期反射へ変更しました。キーを保持しても短く終わり、note-onごとに再発音します。

試聴フィードバックではRain / Helicopterが採用可能、Applause / Gunshotがドラムのように聞こえるとのことでした。後者2音色を再調整しています。固定ゲイン・リバーブなし・MIDI 60 / velocity 100で、0〜300 Hzのエネルギー比はApplause（先頭2秒）が約1.06%→0.21%、Gunshot（先頭200 ms）が約82.90%→2.51%に変わりました。矩形窓DFTによる帯域比であり、自然さの評点ではありません。Rain / Helicopter / Seashoreはパラメータと2秒の比較レンダーが再調整前と同一です。

録音サンプルではなく、合成による近似です。実際にどの程度それらしく聴こえるかは、比較音源で確認してください。

Rainプリセットも、帯域ノイズの音量・明るさを16 HzのSample & Holdで変える方式から変更しました。一定の雨のざわめきに、6組の独立したタイマーによる短い雨滴音を重ねています。雨滴ごとに強さと1200–4500 Hzの共鳴周波数をばらつかせ、6 msの減衰時定数で短く終わらせます。大きなフィルターの飛びや長い残響を抑え、GMのFX 1 (rain)への割り当てを維持しています。Seashoreのパラメータと音源処理は今回変更していません。

## 出力レベルと互換性

変更した10プリセットは、既存の共通試奏フレーズで約−18 LUFSへ再調整しています。フリーリードのノイズを除いた後のレベルや、FXの短い発音で音量が変わるためです。あらゆる演奏・音域で同じ音量になる保証ではありません。

変更した内蔵プリセットを選び直すと新しい値になります。以前に保存したパラメータは自動で書き換えません。従来のNoise Typeの値、パラメータIDとスライダー順は維持しています。Free reedのDSP修正は、そのモデルを使用する保存済み音色にも適用されます。

## 比較セットの作成

```sh
npm run audition:timbre
```

`.cache/timbre-audition/` に現行の10音色のWAV、MIDI、プリセットJSON、レベル測定表、オフライン試聴ページを生成します。REAPERや追加パッケージは不要です。

古い版との比較:

```sh
node scripts/timbre-audition.js --baseline /path/to/old-checkout --out /path/to/listening-pack
```

再調整した2音色だけを比較する場合は `--only Applause,Gunshot` を追加できます。比較基準に「ドラムのように聞こえた版」のコミット `2261eac8f0c7ed9cc23da3dba720d28f209541d3` を使うと、今回の再調整との差が分かります。

`--baseline`には、比較したいコミットのcheckoutか、`git archive`を展開したディレクトリを指定します。変更前の基準はPR #20を含むmainの `5882567155dfeff02821607e22c82f0e44fcbbac` です。JSONだけではなく、その版のDSPも使って修正前をレンダーします。

生成した `listen.html` をブラウザーで開き、音色を選んでA/Bを同じ時刻で切り替えてください。「音量を揃える」で音色を比較し、「元の音量」で低音域の過大ノイズやプリセットの出力差を確認できます。ページとWAVは同じフォルダーへ置きます。

比較用は全体への一定ゲインでLUFSを揃えます。ベロシティの差や減衰を圧縮せず、sample peakを−1 dBFS以下に収めるため、必要に応じて共通LUFS目標を下げます。特に短いFXでは、LUFS一致だけで知覚上の音量一致とは言えません。MIDIにProgram Changeは含めていないので、REAPERで使う場合は音色を明示的に設定してください。

## 自動確認の範囲

- フリーリード: 低音〜高音で息ノイズがリード音を覆わない、ムゼットを含む発音、Breath Noiseの効果が残ること。
- FX: 回転翼の周期的な発音、拍手の短い不規則な発音、保持中の破裂音の終了、同じキーの再発音、ミュート解除時の古い破裂音の防止、リリース、音高への非依存。
- JS/JSFX: 44.1/48 kHzでのサンプル比較、再発音とNoise Clockの設定違い。
- 全プリセットの出力レベル、生成されたスライダー／カタログの一致。

これらは信号・動作の確認です。聴感上の自然さを保証するテストではありません。
