# 三味線・シタール：参照MP3と現行モデルの分析

作成日：2026-10-17（日本時間）
対象コード：`f1da591860dba51cede4490f666f9e0c441fcb3f`

以下の分析本体は上記コミットの音を基準にした記録です。同日、その結果に基づく第1段階の実装を行いました。実装内容・比較結果は末尾の追記を参照してください。

参照MP3と`.cache/`以下の測定・音声成果物はローカル資料で、リポジトリの配布対象には含めません。実装後の前後比較音源は、同梱の`scripts/string-reference-review.js`から再生成できます。

## 結論

三味線は「さらに撥音を大きくする」より、**短い撥音と、その後に残る弦・胴の響きの釣り合い**を改善したい。特に高音でアタックだけが突出する現象を先に扱う。

シタールは**明るい初期励振を抑え、持続中に変化するジャワリ、音程の連続変化、選択的な共鳴弦**を作り込む方向が有力。共鳴弦のミックスを一律に上げるだけでは不足する。

これは信号解析・スペクトログラム・ソース確認からの改善仮説であり、直接試聴による音質判定ではない。音源実装と既存プリセットは変更していない。

## 資料と測定方法

- Shamisen.mp3（ローカル: `Shamisen.mp3`）：デコード後169.041秒、元データ48 kHz / stereo、約128 kbps。
- Sitar.mp3（ローカル: `Sitar.mp3`）：デコード後967.401秒、元データ48 kHz / stereo、約97 kbps。
- 全編を24 kHz / monoへ変換して解析。スペクトル統計は80 Hz〜10 kHzの帯域を対象とした。
- 5 ms単位のエネルギー上昇から発音候補を抽出。検出間隔は最低180 ms、立ち上がり位置を最大30 ms戻した。候補数は三味線498、シタール2,879。
- 発音候補の5〜25 msを「初期」、80〜160 msを「後続」と呼び、RMS差、Welch法のパワー重心、3 kHz以上のエネルギー比を集計。
- 現行JS DSPは各プリセットそのまま、MIDI 48 / 60 / 72、velocity 100、3秒でnote-off、全長4秒を生成。同じ窓で測定。解析にはPCM量子化前のfloat出力を使用し、確認用16-bit WAVも保存した。Roomと共鳴弦はプリセット値を維持。

**限界：** 自動検出点は検証済みの単音発音点ではない。誤検出・検出漏れ・30 ms程度の位置誤差、前音、速い連打、伴奏、残響、録音EQ、圧縮の影響がある。全編統計は「録音全体の特徴」であり、対象楽器だけを分離した測定ではない。参照と生成音は音程・奏法・録音条件を一致させていないので、数値をそのまま最適化目標にしない。参照録音から実楽器のT60、胴の固有周波数、さわり量、弦数・調弦を同定したとは扱わない。

## 三味線：改善したいところ

### 1. 撥音の強さと弦の持続を別々に調整する（最優先）

参照の22.885〜30.885秒の図には、短い広帯域の立ち上がりと、その後に残る主に低中域の倍音が見える。例えば83.225秒の候補では3 kHz以上の比率が初期56.1%から後続0.79%に変わる。鋭い発音自体は参照にも存在するので、全体を暗くするだけでは特徴を失う可能性がある。

現行はMIDI 72で初期−後続差が15.31 dBと大きい。note-off前の0.1→0.6秒のRMS低下も約24.9 dBで、MIDI 48 / 60の約20.7 / 21.7 dBより速い。これは現行モデル内で確認できる音域依存であり、参照の同じ音高より短いと実証したものではない。

現在の`string_plectrum`は弦の初期変位と撥接触パルスの両方に作用する。弦の太さを変えずに撥だけを下げにくいため、**弦励振量・撥接触量・胴への入力を分ける**のがよい。発音比率を大きくする既存テストだけを音質目標にすると、この偏りを見逃す。

### 2. 胴・皮を「アタック専用の高域3モード」から拡張する

現行の共鳴周波数は950 / 2,300 / 4,800 Hz、減衰設定は硬さ補正前30 / 18 / 10 ms。入力は`0.002 * direct + contact`なので、持続弦からの励振が小さく、撥の瞬間の寄与が中心になる構造。

**短い皮の接触音と、弦から継続的に駆動される胴の共鳴を別経路にする**案を優先する。前者の鋭さを残しつつ、後者で中低域の厚みを試す。今回の録音だけから追加モードの正確な周波数を決めることはできないため、モード位置・帯域幅を候補比較する。過去に避けた木片的な低音を戻さないよう、低域量と減衰時間を分けて調整する。

### 3. 三味線用のさわり挙動を分ける

現行の`string_sawari`はシタールと共通の折り返し非線形。しきい値が振幅包絡に追従し、接触損失を利得補償するため、音が小さくなっても相対的に似た接触条件を維持しやすい。

三味線では、接触しきい値・接触の硬さ・振幅依存・対象弦を別に扱うモデルを試す価値がある。ただし、この録音から弦ごとのさわり構造は分離できていない。全音に同じbuzzを増す案より、開放弦／押弦や強弱で効果を変える仮説として検証する。

## シタール：改善したいところ

### 1. 初期励振の高域を抑え、ジャワリの時間変化を別に制御する（最優先）

録音は初期・後続とも低中域の比重が大きく、現行のノイズ由来の明るい初期励振とは大きく異なる。まず`string_brightness`を下げる試作が妥当。ただし全音をローパスで暗くしただけでは、ジャワリ由来の倍音変化も一緒に消えてしまう。

現在は`string_brightness=0.85`、`string_sawari=0.65`。励振の明るさを下げる操作と、振動中に倍音を作る接触モデルの操作を独立に比較したい。後続倍音の出方を見ながら、**音量の減衰とbuzzの減衰を独立に調整できる**設計にする。振幅に比例する接触しきい値だけでなく、固定成分を含むしきい値や接触の柔らかさを実験する。

### 2. 音程の連続変化を入れた状態でモデルを評価する

425.985〜433.985秒のスペクトログラムには、上下に連続して動く複数の倍音の筋が見える。これは固定音を並べる評価では捉えられない重要な比較対象。楽器ごとの正確な奏法名やピッチ変化量までは今回同定していない。

現行にはピッチベンドが既にあるので、最初はMIDIベンドで同種の曲線を作り、遅い揺れ・大きなスライドを含めて評価する。共鳴弦はベンドしない現在の仕様を保持し、旋律だけが動く例も比較する。実装追加の前に既存機能で試せる。弦張力と接触条件を連動させる改修は、その後の候補。

### 3. 共鳴弦を、音階から選んだ調弦と倍音を持つモデルへ

現在はRootから連続する24音に、各1個の共鳴器を置く。既定の12平均律では半音刻みであり、カスタム音階を選んだ場合はその音階に従う。共通の残響として鳴り続ける土台は既にあるが、共鳴弦ごとの倍音・接触特性は持たない。

改修候補は**共鳴する音の集合を明示指定すること、各弦に少数の倍音を追加すること、旋律・ドローン・共鳴弦の役割を分けること**。RootやMixだけで合わせるより、特定の音程で応答が強くなる構造を作れる。ただし参照の低域持続成分が共鳴弦・別弦・伴奏のどれかは未分離なので、今回の数値から調弦やMixを決定しない。

## まず試すパラメータと実装順

以下は未試聴・未評価の探索範囲。採用値ではなく、他の値を固定して1項目ずつ比較する。

| 対象 | 現行 | 最初の比較候補 | 確かめたいこと |
|---|---|---|---|
| 三味線 Body Mix | 0.65 | 0.40 / 0.55 / 0.65 | 特に高音で撥音が突出していないか |
| 三味線 String Decay | 1,800 ms | 1,800 / 2,400 / 3,000 ms | アタックを保ちながら後続弦音を残せるか |
| 三味線 Plectrum | 0.80 | 0.60 / 0.70 / 0.80 | 弦励振も同時に変わる副作用を含めて比較 |
| シタール Brightness | 0.85 | 0.40 / 0.55 / 0.70 | 初期ノイズの高域を抑えられるか |
| シタール Sawari | 0.65 | 0.35 / 0.50 / 0.65 | 暗い励振と組み合わせてもbuzzの輪郭が残るか |

Decayを延ばしてもループ内のDampingによる高域損失は残る。Brightnessを下げてもSawariは後から高域を再生成する。どちらも単独パラメータで参照に一致するとは限らない。

実装は、①音域別のアタック／持続バランスと励振の調整 → ②撥・弦・胴経路の分離 → ③三味線とシタールの接触モデル分離 → ④共鳴弦の調弦・倍音拡張、の順を提案する。ベンドを含む演奏比較は①から並行する。

比較時はMIDI 48 / 60 / 72に加え参照で確認した音高、velocity 70 / 100 / 120、単音・連打・開放弦相当・ベンドを使い、音量を揃えて試聴する。参照の発音点と音高を手動で確認してから数値目標を絞る。今回の録音全体の中央値への単純な合わせ込みは避ける。
